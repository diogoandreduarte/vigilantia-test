# Notas de Dependências — Vigilantia

Comandos e notas adicionais para garantir o correto funcionamento do projeto.

---

## Setup Rápido (Recomendado)

Corre o script de setup — trata de tudo automaticamente:
```
bat\setup.bat
```

O script cria o `.venv`, instala todas as dependências via `pyproject.toml` e instala o Playwright Chromium.
Só é necessário fazer setup completo na primeira execução.

---

## Ambiente Virtual (Manual)

Criar e ativar (Python 3.14):
```
py -3.14 -m venv .venv
.venv\Scripts\Activate
```

Se der erro de política de execução no PowerShell:
```
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

---

## Instalação de Dependências (Manual)

Instalar a partir do `pyproject.toml` (fonte de verdade):
```
pip install -e .
pip install pytest
```

> Nota: o `requirements.txt` apenas lista dependências de desenvolvimento adicionais.
> Usar sempre `pip install -e .` para instalar o projeto e as suas dependências.

---

## Passos Adicionais Após Instalação

### Playwright (browsers)
Após instalar o pacote, é obrigatório instalar o browser:
```
python -m playwright install chromium
```

### WeasyPrint (PDF)
Em Windows o pip instala tudo automaticamente.
Se houver erros com fontes ou Cairo, consultar:
https://weasyprint.readthedocs.io/en/latest/install.html

---

## Atualização de Dependências

Sempre que instalar um pacote novo:
1. Adicionar ao `pyproject.toml` (secção `dependencies`) — é a fonte de verdade
2. Registar aqui se precisar de passos manuais adicionais
